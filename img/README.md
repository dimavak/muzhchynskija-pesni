# Фота на сайце

Старыя фота і паштоўкі з мясцін, адкуль паходзяць песні (паветы Ваўкавыскі, Слонімскі, Навагрудскі, Лідскі, Гродзенскі, Слуцкі).
Усе ў грамадскім набытку. Апрацоўка аднолькавая для ўсіх: кадраванне, аўтакантраст, лёгкае зерне і дуатон #181112 → #F4EDE3.
